# 보안과 개인정보

## 실행 경계

기본 UI는 `127.0.0.1`에만 바인딩하는 로컬 HTTP 서버입니다. 허용된 Host와 Origin을 확인하고, 상태를 바꾸는 요청에는 프로세스별 토큰을 요구합니다. CSP로 외부 리소스·프레이밍 등을 제한하며, UI는 문서와 AI 응답을 텍스트 노드로 표시합니다.

이 서버는 공개 인터넷 배포나 다중 사용자 서비스를 위한 인증·권한 시스템을 제공하지 않습니다. 원격 접속을 위해 바인딩 주소를 바꾸거나 프록시로 공개하는 사용 방식은 검증 범위 밖입니다. 로컬 악성 프로세스나 브라우저 확장으로부터 데이터를 격리하는 샌드박스도 아닙니다.

스킬 설치·실행, 셸 실행, 모델 변경, 에이전트 위임을 제공하지 않습니다. 장바구니 저장과 요청문 내보내기는 사용자의 선택을 기록할 뿐 다음 행동을 승인하지 않습니다. 선택적 MCP도 읽기·검색·검사·추천만 노출합니다.

## 로컬 문서와 저장

기본 검색 범위는 직접 작성한 예제가 있는 `examples/skills`, `examples/project`입니다. 사용자가 루트를 바꾸면 그 범위의 문서를 로컬 색인으로 읽습니다. 프로젝트 문서 탐색은 Markdown·TXT·RST와 파일 크기 제한을 사용하고 숨김·제외 디렉터리, 심볼릭 링크와 루트 밖 경로를 제한합니다.

문서 읽기 API는 색인에서 얻은 문서 ID와 줄 범위를 받으며 임의 경로를 읽도록 설계하지 않았습니다. 그래도 설정한 검색 루트에 민감한 문서를 넣으면 해당 내용이 로컬 SQLite DB와 화면에 나타날 수 있습니다. 루트는 필요한 범위로 지정하세요.

생성되는 SQLite 색인은 문서 본문을 포함합니다. 장바구니 파일과 브라우저 localStorage에는 선택과 목표가 남습니다. 내려받은 Markdown도 사용자 데이터입니다. 이 자료는 암호화 보관소가 아니며 공개 저장소나 공유 파일에 포함하지 않아야 합니다. AI 미리보기와 요청 상태는 서버 메모리에만 보관하고 만료된 항목을 정리합니다.

## 선택적 외부 전송

AI를 사용하지 않으면 검색과 기본 추천에 외부 모델 요청이 필요하지 않습니다. AI는 서버 프로세스의 `ANTHROPIC_API_KEY` 환경변수를 사용하며 키를 브라우저에 보내거나 `.env`에서 자동으로 불러오지 않습니다.

사용자가 전송 미리보기를 확인하고 요청하면 작업 목표, 후보 ID·설명, 근거 발췌가 Anthropic으로 전송됩니다. 프로젝트 문서는 사용자가 포함을 선택할 수 있습니다. 실제 로컬 경로는 전송 필드에서 제외하고, 명백한 키·이메일·경로 패턴을 마스킹합니다. **패턴 마스킹은 모든 개인정보·영업비밀 탐지를 보장하지 않습니다.** 미리보기 내용을 사람이 확인해야 하며 공급자의 처리·보관 정책이 적용됩니다.

모델 ID·API 버전과 비용 단가는 코드의 설정값입니다. 입력 32,000토큰·출력 8,192토큰·추정 최대 US$0.01·전체 45초 제한을 적용하고 자동 재시도하지 않습니다. 비용 검사는 공급자 계정의 실제 청구 상한이 아닙니다. 취소는 로컬 결과 처리를 중단하고 가능한 경우 연결을 닫지만 원격 처리와 과금 중단은 보장하지 않습니다.

## 근거와 응답 검증

- 원문은 지시문이 아닌 신뢰하지 않는 근거 자료로 취급합니다.
- 미리보기의 후보는 현재 활성 목록에 묶고 원문의 SHA-256을 저장합니다. 전송 전후 원문이나 등록 경로가 달라지면 결과를 거부합니다.
- 만료·사용된 미리보기와 중복 요청 ID를 거부합니다. 동시 AI 요청은 한 건으로 제한합니다.
- JSON 계약, 중복 키, 필드, 문자열 길이, 후보 ID와 해당 스킬에 연결된 근거 ID를 검사합니다. 잘린 응답과 정상 완료가 아닌 종료도 거부합니다.
- 호환성은 모델의 주장과 분리해 로컬 규칙으로 다시 확인합니다. 모델에 도구 실행 권한을 주지 않습니다.

이 검증은 근거 없는 ID나 변경된 문서를 걸러내기 위한 것입니다. 유효한 ID를 인용한 부정확한 설명까지 참으로 만들지는 못합니다. 최종 판단에는 원문과 실제 실행 환경 확인이 필요합니다.

## 공개 자료와 라이선스

공개 패키지에는 실제 개인 설명서, 개인 번역 자료, 원본 연구 자료, 원시 실행 로그, API 키를 포함하지 않습니다. 기본 예제의 설명과 조합 관계는 시연용입니다. 외부 스킬을 연결할 때는 해당 자료의 이용 조건을 별도로 확인해야 합니다.

저장소 자체의 라이선스는 소유자 결정 대기 중입니다. 이 문서는 별도의 재사용 허가나 외부 자료의 권리를 부여하지 않습니다.
